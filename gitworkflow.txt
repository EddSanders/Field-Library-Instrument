Git Work Flow

					Helpful commands 
						git clear
						git -h (help)
						git --help
						git log -h 
						git log --help (opens help in browser)
						
Git Config 
	git config --global user.name "your name" 
	git config --global user.email "your.email@example.com"
	git config --global --list

Create Folder
	right click, "show more options", open git bash here
	git init (initialise the project folder into a git local folder)
		(this will create a hidden folder)
	git status

Create File
	echo "hello git!" >hello.txt
	git status
	git add hello.txt (to stage a specific file name type first few letter and tab)
	git commit -m "added new file" (-m means message)
	git log (presents details)
	
Modify the File and Track Changes
	Edit File
	git status (changes not staged for commit)
	git diff (shows the differences)
	git add . (stage all the changes) filename (for specific file)
	git status (ready to be commited)
	git commit -m "hello.txt"
 	git status (everything is commited)
	git log (displays the commits)
	
Commit History and File Versions
	git log
	git log --oneline (show log on one line)
	git show HEAD~1:file.name
	git diff HEAD~1 HEAD (shows what has changed between file commits)

Create and Switch Branches
	git branch (shows you current branches)
	git branch branchname (creates a new branch)
	git branch (shows new branch)
	git checkout branchname (switch to new branch)
	(make changes to file, whatever is changed will be only changed on current branch)
	git checkout main (switch to main or master branch)
	git merge branchname (merges the changes to braches)
	git branch -d branchname (-d means delete)

Push to the GitHub repository 
	git remote add origin (weblink from GitHub)
	git branch -m main (renaming branch to main compatable with GitHub)
	git push -u origin main
